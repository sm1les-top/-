# Мяумур (Fabric, Minecraft 1.21.11)

Предмет **Мяумур** с 3D-моделью из ресурспака meowmur3D.

- ПКМ — выстрелить бессмертным котом
- Shift + ПКМ — собрать всех выпущенных котов в радиусе 128 блоков
- Креатив: вкладка «Боевые предметы»

Сборка: вкладка Actions на GitHub → артефакт `meowmur-mod` (jar). Нужен Fabric Loader + Fabric API.
